# 波利AI图助手 Chrome 插件

## 调试安装

1. 打开 Chrome：`chrome://extensions/`
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹：`chrome-extension`。
5. 保持“波利AI图助手”桌面软件正在运行。

## 使用方式

- 在网页图片上右键，选择“保存到波利AI图助手”。
- 在网页里拖动图片时，右下角会出现“拖到这里”，把图片拖进去即可加入软件队列。
- 也可以继续把网页图片直接拖到波利悬浮球；如果浏览器提供图片 URL，软件会自动下载并导入。

## 本地接口

桌面软件监听：`http://127.0.0.1:17367`

- `GET /health` 检查软件是否启动。
- `POST /import-image` 导入图片，支持 `{ "url": "..." }` 或 `{ "dataUrl": "...", "fileName": "..." }`。
