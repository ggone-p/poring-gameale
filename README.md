# 悬浮式投放图上传加工工具

这是一个 Windows 桌面小工具，用于把发行设计做好的投放图快速写入飞书多维表格、按表格生成的 `素材完整命名` 输出本地文件，并上传最终成品图到 `成品` 附件字段。

## 运行

开发调试时运行：

```powershell
npm install
npm run dev
```

如果 Electron 二进制下载失败，可使用国内镜像重新触发安装：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
node .\node_modules\electron\install.js
```

## 打包 EXE

生成可安装的 Windows EXE：

```powershell
npm run dist
```

打包完成后到 `release` 文件夹里找安装包，例如：

```text
release/素材悬浮上传 Setup 0.1.0.exe
```

如果只是想生成一个免安装目录用于内部测试：

```powershell
npm run pack
```

## 首次配置

### 1. 创建飞书自建应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app)。
2. 进入企业后台，创建“企业自建应用”。
3. 在“凭证与基础信息”里复制 `App ID` 和 `App Secret`。
4. 在“权限管理”里开通多维表格记录读写、字段读取、附件/素材上传相关权限。
5. 发布应用版本，确保当前企业可用。

### 2. 授权多维表格

1. 打开你的多维表格链接。
2. 点击右上角“...”或“自动化/高级权限”相关入口。
3. 将刚创建的自建应用添加为协作者，至少给它编辑权限。
4. 当前表格链接里的 `app_token` 已默认写入工具：`<your_app_token>`。

### 3. 在工具里连接

1. 打开悬浮按钮，点击设置。
2. 填写飞书自建应用的 `app_id`、`app_secret`。
3. 确认 `app_token` 是 `<your_app_token>`。
4. 点击“同步字段”，工具会读取表列表和字段列表。
5. 选择对应的数据表。
5. 确认字段映射：
   - `language` -> `语言`
   - `size` -> `尺寸`
   - `assetContent` -> `素材内容`
   - `detailContent` -> `细分内容`
   - `designer` -> `设计师`
   - `creative` -> `创意`
   - `completionDate` -> `完成日期`
   - `fullName` -> `素材完整命名`
   - `finalAsset` -> `成品`
   - `progress` -> `进展`
6. 选择本地 `Logo`、`Slogan`、`Icon` 素材库文件夹。
7. 点击“保存设置”。

## 工作流

1. 点击悬浮按钮展开窗口。
2. 拖入或选择成品图。
3. 填写从飞书字段同步来的选项。
4. 可选启用 logo / slogan / icon，选择透明图片素材并微调位置和大小。
5. 点击“上传并重命名”。

工具会按顺序执行：

1. 在飞书多维表格中新建一行。
2. 等待并读取表格自动生成的 `素材完整命名`。
3. 生成叠加后的最终图片。
4. 上传最终图片到飞书 `成品` 字段。
5. 写入 `进展=已完成all`。
6. 删除源文件，仅保留按 `素材完整命名` 命名的最终文件。

## 注意

- 源文件会被最终命名文件替换；上传前请确保这符合当前批次需求。
- 如果 Photoshop、资源管理器预览或其他程序占用了图片，最后的删除/重命名可能失败，工具会保留错误状态用于重试。
- 飞书接口需要自建应用具备多维表格记录读写、素材上传等权限。
